# Polaris v1.3.4 SteamOS Release Preparation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Prepare Polaris v1.3.4 and add a separately built, validated SteamOS 3.8 x86_64 release artifact without publishing, installing, or deploying the release.

**Architecture:** Keep the existing rolling Arch package lane unchanged. Add a SteamOS job that starts on an Ubuntu runner, launches a privileged disposable Arch bootstrap container, pins and hashes Valve's `holo-keyring`, creates a clean signed SteamOS 3.8 root with `pacstrap`, and builds a SteamOS-only PKGBUILD inside that root. Package validation installs only into the disposable root, checks metadata, dependencies, payload, dynamic links, ABI provenance, binary path hygiene, and source identity, then exports the package and receipts for release assembly.

**Tech Stack:** GitHub Actions, Bash, Docker, pacman/pacstrap, makepkg, CMake/Ninja, Vitest, ShellCheck, npm audit, Git, SHA-256.
