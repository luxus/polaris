# Polaris v1.3.4 SteamOS Release Preparation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Prepare Polaris v1.3.4 and add a separately built, validated SteamOS 3.8 x86_64 release artifact without publishing, installing, or deploying the release.

**Architecture:** Keep the existing rolling Arch package lane unchanged. Add a SteamOS job that starts on an Ubuntu runner, launches a privileged disposable Arch bootstrap container, pins and hashes Valve's `holo-keyring`, creates a clean signed SteamOS 3.8 root with `pacstrap`, and builds a SteamOS-only PKGBUILD inside that root. Package validation installs only into the disposable root, checks metadata, dependencies, payload, dynamic links, ABI provenance, binary path hygiene, and source identity, then exports the package and receipts for release assembly.

**Tech Stack:** GitHub Actions, Bash, Docker, pacman/pacstrap, makepkg, CMake/Ninja, Vitest, ShellCheck, npm audit, Git, SHA-256.

- [ ] **Step 1: Implement the outer bootstrap script**

The script must:

1. Require execution inside a disposable privileged container.
2. Install only bootstrap tools from the initial Arch container.
3. Initialize the pacman keyring.
4. Download exactly `holo-keyring-20250801-1-any.pkg.tar.zst` from Valve's HTTPS mirror.
5. Verify SHA-256 `a5efa4f9c161ce9607fd9dfcccaf2a587baa9acd35eae04d3c01d967dddc9722` before the one-time local install.
6. Use a temporary `SigLevel = Never` config only for that already hash-verified keyring file.
7. Configure `jupiter-3.8`, `holo-3.8`, `core-3.8`, and `extra-3.8` with `SigLevel = Required DatabaseOptional` and `LocalFileSigLevel = Required`.
8. Create a clean target directory and populate it with `pacstrap -G -M`.
9. Bind the checkout and output directories into the target.
10. Run `build-steamos-package.sh` through `arch-chroot`.
11. Unmount all binds through a trap.

The target package set must include all build and runtime dependencies from the SteamOS PKGBUILD, plus `ccache`, `namcap`, `shellcheck`, and `binutils` for validation.
